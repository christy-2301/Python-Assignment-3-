 Python Fundamentals Assignment 3

This assignment covers **While Loop, For Loop, Control Statements, and Functions** in Python.

## Topics Covered

- While Loop
- For Loop
- `break`, `continue`, and `else`
- `range()` function
- User-defined Functions

## Programs Included

### 1. Number Guessing Game
A simple number guessing game using a while loop. It allows the user to make 3 attempts and uses `break`, `continue`, and `else` statements.

### 2. Multiplication Table Generator
Generates a multiplication table from 1 to 10 for a number entered by the user using a for loop and `range()`.

### 3. BMI Calculator
Calculates the Body Mass Index (BMI) using a user-defined function. The user enters their weight and height, and the program calculates and displays the BMI.
